# 플래그 메모리 (Flag Memory)

데블스플랜 3에 나온 국기 기억 게임을 웹으로 옮긴 1인용 게임입니다.
국기 10개를 30초 동안 외운 뒤, 25개 국기 중 앞에서 본 국기 5개를 1분 안에 찾아내세요.

▶ 플레이: https://jkh76.github.io/flagmemory/

## 게임 방법

1. **판 수**(3판 · 5판 · 10판)와 **난이도**(하 · 중 · 상)를 고르고 시작합니다.
2. **시작 카운트 3초** 뒤 국기 10개가 1초씩 차례대로 지나갑니다. 같은 순서로 3회 반복(30초)합니다.
3. **가림 5초** 동안 화면 중앙에 카운트다운이 나옵니다.
4. **선택 60초**: 5×5로 놓인 25개 국기 중 앞에서 본 국기를 최대 5개 고릅니다. 다시 누르면 해제됩니다.
   5개를 다 고르면 `제출`로 바로 끝낼 수 있습니다.
5. **결과**: 정답 국기는 노란 테두리, 내가 고른 국기는 파란 테두리로 표시되고 나라 이름이 나옵니다.
   중앙에 "5개 중 N개 정답"이 뜹니다.
6. 정한 판 수를 모두 마치면 판별 점수와 **합산 점수**를 보여줍니다.

## 규칙

- 25개 중 정답은 항상 5개(외운 10개 중 무작위 5개), 나머지 20개는 외우지 않은 국기입니다.
- 판당 0~5점, 오답 감점은 없습니다.
- 상단 타이머는 남은 10초부터 주황, 5초부터 빨강으로 바뀝니다.
- 한 게임 안에서 외운 국기는 다시 나오지 않습니다. (국기가 모자라면 다시 섞어 씁니다.)

## 난이도

국기는 올림픽 참가국(IOC 회원 NOC) 기준입니다.

| 난이도 | 국가 수 | 오답 국기 |
| --- | --- | --- |
| 하 | 50개국 (잘 알려진 나라) | 정답과 비슷한 국기 제외 |
| 중 | 103개국 | 무작위 |
| 상 | 205개국 (전체) | 정답과 비슷한 국기 우선 (예: 루마니아·차드, 인도네시아·모나코) |

차이니스 타이베이는 올림픽 전용 깃발을 써서 제외했습니다.

## 기술
